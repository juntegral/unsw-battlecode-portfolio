# unsw-arena

UNSW Battlecode(심해 드래곤 게임) 봇을 **규칙에서 출발해 끝없이 개선**하는 저장소. 목표는 최적의 로직을 찾고 계속 성장시키는 것이다. 사이트 점수나 특정 상대 성적은 목표가 아니다.

## 먼저 읽을 것
1. `lineages/BRIEF.md` — 규칙서 위치, 심판 한도, 도구, 작업 규칙.
2. `lineages/LOOP.md` — 무한 개선 사이클.
3. `lineages/GROWTH.md` — 성장 판단 원칙.
4. 네 계통의 `lineages/<이름>/CURRENT.md` — 현재 최선·진행 상태. 없을 때만 `NOTES.md`에서 현재 상태를 복원한다. 과거 기록은 필요한 부분만 찾는다.

## 구조
| 경로 | 내용 |
|---|---|
| `rules/` | 공식 문서 저장본(프로토콜 3.0.0)과 심판 한도 |
| `lineages/<이름>/` | `bot/` = 최선 버전, `CURRENT.md` = 짧은 현재 상태, `NOTES.md` = 실험 이력, `checks/` = 채택 전 확인 근거 |
| `lineages/_tools/` | `unswbc`(공식 1.1.0 실행기), `eval.js`(표준 벤치마크 160판), `export_replay.js` |
| `lineages/_eval`, `_releases`, `<이름>/logs` | 공유 데이터 폴더로 가는 링크(벤치마크 결과, 배포 스냅숏, 온라인 기록) |
| `bots/` | 로컬 상대 봇(실행만, 소스 읽지 말 것) |
| `maps/` | 현재 온라인 지도 풀 10개 + 번들 지도 13개 |
| `loop/` | 무한 웨이브 루프 스크립트와 웨이브 프롬프트 |

## 휴리스틱 연구 (2026-09-29 사용자 결정)
운영자(사용자와 Claude)의 휴리스틱 연구는 별도 저장소 `../unsw-heuristic`에서 하며, 그 저장소의 규칙을 따른다. 그 규칙은 원격 작업 전면 허용, 로컬 상대 실행·분석 허용이다. 아래 절대 규칙은 이 저장소의 무인 루프(계통 에이전트)에 적용된다. 무인 루프는 일시정지 상태다.

## 절대 규칙
- 서버 접근·업로드·API 키 파일(`~/Downloads/api.txt`) 읽기 금지. 새 버전 제출은 배관 데몬(이 저장소 밖)이 한다. 배관 데몬은 온라인 대전을 새로 요청하지 않는다.
- 맡은 계통 폴더 밖은 수정하지 않는다. 다른 계통 폴더와 상대 봇 소스(확인용 사본 포함)는 읽지 않는다.
- 로컬 경기는 공통 실행 큐(`loop/run-job.js`, `loop/check.js`)를 이용한다. 한 평가 안에서 동시 2개까지, 디스크 여유 20GB 미만이면 새 경기 중단.
- macOS 서명·보안 설정을 우회하지 않는다.
