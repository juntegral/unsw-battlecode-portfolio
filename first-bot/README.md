# First bot (solo phase)

A snapshot of my first repository for the contest (`unsw-heuristic`, private, 133 commits): a heuristic C++ bot,
the tools around it, and the research that ended the line.

| Path | What it is |
|---|---|
| `bot/` | The bot: world model, planner, protocol |
| `bots/` | Local stand-in opponents built to imitate strategies seen on the ladder |
| `tools/` | Evaluation, replay export, online client, studies of top teams' games |
| `research/` | Plans, observations, and `CHECKPOINT-2026-10-01.md`, the review that concluded that adding features one at a time was not moving results against the top teams |
| `exp/` | One folder per experiment: scripts and reports. Bot copies, logs and bulk output are left out |
| `CLAUDE.md` | The working rules given to the AI sessions (Korean) |

The contest SDK header, the organisers' maps and rule text are not included.
