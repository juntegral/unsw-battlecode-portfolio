# [M/C/E] 재현과 해석 범위

[M] `analyze.py`는 기존 `approach/scan.py::Board`와 공용 Cap'n Proto 리더를 import한다. 입력은 one5-w1/c1, one7-w1/c1 각 15판, 총 60판이다. 기보의 우리 botId가 각각 20980/21086인지 검사했다. `inventory.json`, 각 `game-*.json`에 입력 경로·해시·상대 botId가 있다. 네트워크·게임 실행은 하지 않았다.

| 분류 | 정의 |
|---|---|
| [M] 시간 | 기보 r0–150의 **라운드 말**, 10라운드 간격. r0은 초기 배치가 아니라 첫 차례들이 끝난 상태. 종료 뒤에는 종료 상태 유지, CSV의 `ended=true`. |
| [M] all bearing | **그 경기 전체에서 한 번이라도 진주가 생성된 모든 칸**. 자연 진주와 사체 진주 모두 포함. 사용자 요청의 문자 그대로다. |
| [M] natural bearing | 사망 직후 `ceil(L/2)`개의 생성 사건을 사체로 분리하고, 나머지 자연 생성이 한 번이라도 일어난 칸만 사용. 자연 생산지 분석을 위한 보조 분모다. |
| [E] 분모 한계 | 둘 다 경기 후 알게 된 칸 집합이다. 미래 정보는 진단에만 사용하며 봇에게 주지 않는다. 사체 포함 집합은 머리가 움직이다 죽은 곳을 먹이터로 세어 고립을 숨긴다. 자연 집합도 점유로 생성이 막힌 칸·느린 생산지를 누락할 수 있다. 생산량 가중치도 없다. |
| [M] 거리 | 토러스·벽·포털을 반영한 최단 걸음. 몸은 무시한다. 머리→칸 다중시작 BFS. 60판 모두에서 모든 통행 변이 역변을 가짐을 검사했으므로 칸→머리 거리와 같다(`graph-symmetry.json`). 순간 이동의 실제 안전성·시간·관측 가능성은 아니다. |
| [M] 점유 | 전체 bearing 칸 중 우리 최근접 머리가 상대보다 **엄격히 가까운** 칸. 동률은 양편 모두 미포함; 양편 모두 도달불가도 별도. 따라서 양편 합계가 100%일 필요 없다. |
| [M] 평균 거리 | 해당 편이 도달 가능한 bearing 칸의 거리 합/칸 수. 도달불가 거리는 무한대이므로 유한 평균에 섞지 않고 `unreachable`을 별도 보고한다. |
| [M] H/V | 그 편의 전체 머릿수 / 모든 머리의 7×7 시야 **합집합**에 들어온 bearing 칸 수. 중복 시야 칸은 한 번. 분모 0은 NA. CSV의 `local_head_tile_pairs`는 중복 포함 머리–먹이칸 시야 쌍 수도 제공한다. |
| [M] 고립 | 그 편 머리 중 도달 가능한 bearing 칸이 4걸음 이내에 없는 비율. |
| [M] 혼잡 | 그 편 머리 중 자신을 제외한 아군 머리가 2걸음 이내에 하나라도 있는 비율. 몸·벽 뒤 맨해튼 근접을 혼잡으로 세지 않는다. |
| [M] 합산 | 점유·거리는 칸 수로 가중, 고립·혼잡은 머릿수로 가중, H/V는 분자·분모를 각각 합산. 머릿수·자연 섭취는 판당 평균. 전멸은 머릿수 비율 분모에 기여하지 않으며, 진주·머릿수 판당 평균에는 포함된다. |
| [M] 시점 | `onsets.json`: 최대 차이의 라운드, 이후 모든 관측점에서 차이 부호가 유지되는 최초 라운드. 단일 조기 역전과 지속 열세를 구분. |

[M] `moments.py`는 지정한 one7 5판의 우리 차례를 다시 읽는다. `adjacent_pearl`은 통행 가능한 바로 다음 칸에 **현재** 진주가 있는지이며 몸 장애물은 제외하지 않는다. 가시 7×7 밖의 포털 출구도 포함하므로 봇의 실제 인지 조건이 아니다. 무섭취 구간은 자연·사체 모두 먹지 않았고 분열하지 않은 연속 **행위자 차례**다. 상세는 `turns.jsonl`, `moments.json`. `outside4`는 위 자연 bearing 기준이다.

[M] 검증: 3,840개 행(60판×16시점×2편×2분모), 모든 시점의 `H=H초기+분열−사망` 일치. one5 30판×4시점×양편=240개 체크포인트에서 기존 `o1_scan` 원장의 머릿수·총길이·자연섭취와 일치했다. 각 이동의 끝 꼬리 좌표를 검사했다. [E] 이 검증은 공용 리더의 오류까지 독립적으로 배제하지 않는다. one7은 같은 원장으로 별도 재검산하지 않았다.

[E] 차례별 내부 기억·타이머·각 후보 점수·최종 점수항의 승자를 복원하지 않았다. 따라서 **상수 켜짐**과 **행동을 결정했다는 인과적 binding**은 다르다. 보고서의 binding 미확인은 실패를 숨긴 표현이 아니라 이 데이터의 한계다.

[M] `verify.py`는 정확히 하나의 기존 constexpr 값만 바꾸는 12행을 검사하고 각각 C++20 `-O2 -fsyntax-only`를 통과시켰다. `verification.json`에 원래 값·제안 값·컴파일 결과가 있다. 실행파일·WASM·CPU·경기 결과 검증은 아니다.

[E] 40개 미지 지도 시험은 같은 지도·시드·편의 one7 기준과 후보를 짝짓는다. ΔP100/150은 자연 섭취 총수 차이, ΔH100/150은 머릿수 총수 차이다. 랭킹은 사전 기대이며 효과 크기는 추정하지 않았다. 각 행의 예측은 ΔP100>0와 ΔP150>0; 어느 한 시점에서 ΔP≤0이면 그 시점의 개선 예측은 반증된다. 둘 다 ≤0이면 경제 개선 후보로 기각한다. ΔH<0이면 섭취 증가가 머릿수 증가로 이어진다는 설명도 성립하지 않는다. 기제 지표는 승패·길이 점수와 별도로 확인한다. 단일 40지도 표본은 통계적 확증이 아니다.
