# 스프린트 본선 지도 복원 (W5 / W8)

작성: 2026-10-01 20:44:52 KST. 오프라인 분석, 커밋·업로드·경기 실행 없음.

**구조는 복원했지만 진주 생성 간격은 추정이다.** 서버가 기보 안 지도 TILE을 모두 0..0으로 바꿨고 pearlCountdown도 남기지 않았다. 이 때문에 원본과 완전히 같은 지도라고 부를 수 없다. 생성 관련 점검에는 이 불확실성을 고려해야 한다.

알려진 지도 10종/15배치, 60기보에서 크기·대칭·켈프·포털 id/짝·드래곤 몸/순서가 공식 파일과 일치했다. 팀은 기보마다 전체 A/B 교환을 허용하며 직접 비교와 교환 여부를 validation.json에 따로 적었다. b 파일은 기존 연구에서 통계로 추정한 판본으로, 공식 원본이라는 독립 보증은 없다. 비교할 배치는 기존 variants.json 분류를 썼으며 그 간격을 복사하지 않았다.

본선 224기보 모두에서 지도별 구조가 전체 팀 교환을 제외하고 같았다. 파일은 첫 드래곤을 A로 정규화하고 원래 순서를 보존한다. MAP_NAME은 원래 이름이다. 초기 진주·무작위 시드·봇은 지도 정의가 아니므로 복제하지 않는다.

간격 추정은 기존 tools/pearl_layout.js의 검증된 점유 재구성과 censored-uniform fitGroup을 사용한다. 턴 전 자연 생성만 표본으로 삼고 사망 낙하는 제외한다. 대칭 칸을 묶고 전부 점유된 구간과 경기 종료를 검열한다. minGap은 깨끗한 표본 최소, maxGap은 우도 추정이다. 관측 안 된 묶음의 0..0은 시험용 가정이며 비생성의 증명이 아니다. 묶음별 표본 수·구간·비생성 한계는 validation.json에 남겼다.

2-core/통로 폭/샘/공급은 lib.metrics 정의를 따른다. off-core는 고립 칸도 포함한다. 사슬은 off-core 끝칸부터 degree=2 줄기를 따라 분기점 직전까지의 칸 수다. 독립 선형 성분은 한 번 센다. 통로 폭 1 비율은 수평·수직 열린 직선 길이 중 작은 값이 1인 칸의 비율이며 degree=2와 다르다. 샘 비율 분모는 생성칸이다. 생성·샘 비율과 공급은 **추정값**이다.

## 독립 점검과 검증기 실행

회귀·산출물 검사 8개와 독립 포털 이동 그래프 7개 대조가 통과했다. 생성 표본 추출의 점유·낙하·최종 상태 검사에서 0이 아닌 항목이 있는 기보는 0개다.

요청한 CLI를 그대로 실행했다: `node --require ./exp/sprint-maps/validate-preload.js tools/mapgen/validate.js maps/sprint`. 기본 모드의 엄격 연결성 실패는 원래 지도의 고립 성분을 그대로 보존한 결과다. `--existing maps/sprint` 실행으로 지도 형식·대칭과 포털·드래곤 제약을 따로 확인했다. preload는 도구가 기본적으로 exp/mapgen에 쓰는 보고서의 목적지만 허용 범위인 exp/sprint-maps로 바꾼다.
