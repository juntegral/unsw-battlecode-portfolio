# Workbench

A snapshot of my main private repository (`unsw-swarm`, 383 commits). It began on 2026-10-01 as a redesigned bot
line and became the workbench for everything after the team formed: tools, the Discord bot, the online harness, the
ladder study, the analysts' work and the operations record.

| Path | What it is |
|---|---|
| `tools/` | meowbot and its helpers, team watchers, online test harness, ladder collector and replay reader, map generator, tests |
| `docs/` | Handovers between lead sessions, the session-state memo, the promises ledger, the desk brief, design diagrams (`arch/`). Mostly Korean |
| `archive/claude-memory/` | Standing rules for the AI sessions, one per file with the reason |
| `archive/final-session-scripts/` | The last day as it ran: switch lists, upload scripts, checks |
| `archive/final-session-agent-reports/` | Analyst reports that had existed only as messages |
| `data/codex/`, `data/analysis/` | Analysts' briefs, scripts and reports; the ladder and top-team studies |
| `data/online/`, `data/local/` | Online test records and local study scripts, without replays |
| `bot/`, `benchmark/`, `versions/` | The swarm bot line, v0 to v1.8, each version with its hypothesis and verdict |
| `eval/`, `exp/`, `research/` | Evaluation reports, experiments (scripts and reports), research notes and briefs |
| `ENGINE.md`, `EVAL.md`, `DECISIONS.md`, `AGENTS.md`, `CLAUDE.md` | Design, evaluation rules, decision log and working rules of the solo phase (Korean) |

Left out of this public copy: the channel mirror, keys, the organisers' rules and maps, replays and logs, and bot
copies inside experiment folders. A few documents cite those paths; they are not published.
