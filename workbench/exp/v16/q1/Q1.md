## 7. 수정: 여왕 id 규칙(23:3x KST; 이 수정 뒤의 판 0판)
- **사실:** 상위권 새 규칙 264판(`data/elite`)에서 A 팀의 가장 작은 시작 id는 0이 129판, 1이 135판이었다. 서버는 편과 무관하게 id를 준다(지도 파일의 DRAGON 줄 순서). 우리 로컬 엔진은 늘 A에 0을 준다(108판 모두).
- **그래서 "A = 0, B = 1"은 온라인 판의 절반에서 틀린다.**
- **바꾼 것:**
  - `World::iAmQueen() = myId ≤ 1`이다. 규칙상 0과 1이 두 여왕이다.
  - `World::queenId()`는 우리가 0/1이면 자기다. 아니면 시야·음파에서 아군으로 아는 0/1이고, 0/1을 적으로 봤으면 다른 쪽이다. 모르면 −1이고, 이때는 대체 규칙을 쓴다.
- **로컬에서 A = 1인 경우:** `exp/v16/q1/maps-flip/`(온라인 10 + 스프린트 7 지도의 DRAGON 팀을 맞바꾼 사본, 우리 A가 id 1)로 잰다.
- 기준(5절)은 그대로다. 수정 빌드로 같은 기준을 다시 잰다(8절).
