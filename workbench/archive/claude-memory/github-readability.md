Every GitHub post (test comments, cards, PRs) opens with a plain-words summary a teammate can read in 20 seconds:
1. What we tried, in one sentence.
2. Did it work, yes/no/unclear, in one sentence.
3. What's needed now (who decides what).

Details and tables come after a "Details" line. No internal tags without a gloss (B61, ES, lspl, Z10c, heldT), no paths, no stats jargon.

**Why:** A teammate checking GitHub for the feeding results found the Codex-written comments too dense to follow.

**How to apply:** put this format into every Codex/loop brief that drafts GitHub text, and check it before posting. Related: [[github-english]], [[discord-msg-style]].
