Every "I'll ..." the user posts in Discord from my drafts is a team commitment. Either do it, or tell the team it changes (and why) before it silently lapses. Track open promises in unsw-swarm/docs/PROMISES.md and check it each turn alongside team_watch.

**Why:** trust inside team meow; the user does not want to say things and drop them.

**How to apply:** before drafting, re-read PROMISES.md; when a draft adds a promise, log it; when work changes a promise (e.g. a result contradicts it), draft a correction message for the user to post. Related: [[discord-msg-style]], [[discord-first]].
