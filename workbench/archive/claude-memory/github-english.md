Anything that goes to GitHub or may be shared with the team (issues, PR bodies, docs, READMEs, loop state/ledger files, dashboards meant for the team) is written in English. Korean is only for talking with the user locally.

**Why:** 10-03 the user said "github에 있는거 앞으로 자료 만들거나 할때는 다 영어로 진행해. 난 어짜피 로컬에서는 너랑만 한글로 대화할꺼니까."

**How to apply:** default to English for every file in the team repo and for loop artifacts; keep chat replies Korean ([[report-in-korean]]). Related: [[discord-msg-style]], [[meow-team-repo]].
