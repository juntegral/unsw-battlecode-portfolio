# How I use AI: six rules, the incident behind each, and whether it held

한국어: [HOW-I-USE-AI.ko.md](HOW-I-USE-AI.ko.md)

Each rule below is one that the record shows was written down after something went wrong. A rule is listed only if
its incident and its source could be checked in this repository. The last column says whether it held to the end of
the contest (2026-10-09 15:00 KST). Rules that were loosened in the last two days are marked "partial" or "no" and
point to [LAST-TWO-DAYS.md](LAST-TWO-DAYS.md). The full set of standing rules, one per file, is indexed in
[`workbench/archive/claude-memory/INDEX.md`](../workbench/archive/claude-memory/INDEX.md).
